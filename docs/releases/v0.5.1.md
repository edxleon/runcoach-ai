The first start signs you in to Garmin on the page, not in the terminal.

```bash
uv tool upgrade runspector      # or, without uv: pipx upgrade runspector
runspector serve
```

**Garmin sign-in where it was built for**
- `runspector serve` on your own computer no longer asks "Sign in now?" in the terminal - a question that Enter answered with yes, so a new user landed in the terminal login. It says to sign in on the page that opens: Setup → *Sign in to Garmin*, with e-mail, password and Garmin's code if your account uses one; the first sync starts right after.
- Served to your network for the phone (`--host 0.0.0.0`), the terminal still offers the login: from the phone the page takes no password.
- `runspector login` works as before, from any terminal.

**Also**
- Installing without uv is named next to it: `pipx install runspector`.
- The README says in its first lines what Runspector is, and the demo video says and shows the new name.
